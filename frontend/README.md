## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Deploy on Vercel

In Vercel, import the repository and set the project root directory to `frontend`. Configure these environment variables:

- `AUTH_SECRET`: the same value configured on the Render backend
- `NEXTAUTH_URL`: the Vercel production URL
- `NEXT_PUBLIC_API_URL`: the public Render backend URL
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`

The backend must set `FRONTEND_URL` to the Vercel URL for CORS.
